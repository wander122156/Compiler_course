# Интерпретатор языка программирования

Краткое описание проекта: интерпретатор собственного языка программирования "Blang" на C#.

## Сборка

### Требования
- .NET SDK 9.0 или выше
- IDE (Visual Studio / Rider / VS Code) или командная строка

### Компиляция
```
dotnet build
```
### Запуск тестов
``` 
dotnet test
```
### Запуск проекта
``` 
cd .\src\Interpreter\
dotnet run test.blang
```
