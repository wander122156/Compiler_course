# Лексические различия Python и C++ (императивная часть)

## Ключевое: Python использует отступы и двоеточия для структуры, C++ — фигурные скобки и точки с запятой. Python динамически типизирован, C++ требует явного указания типов.

### Блоки кода

- Python: отступы (пробелы/tab)

- C++: фигурные скобки {}

Пример:

- C++
````
{
    std::cout << "Hello!";
}
````
- Python
````
    print("Hello")
````

### Ветвления

- Python: if, elif, else + :

- C++: if, else if, else + {}

### Циклы

- Python: while, for in + :

- C++: while, for(;;), do-while + {}

### Функции

- Python: def func(): + :
- C++: тип имя() {} + скобки, обязательный тип возвращаемого значения

### Типы данных

- Python: динамическая типизация (int, float, str)

- C++: статическая типизация, явное объявление (int, float, double, std::string)

### Операторы

- Python: and, or, not
- C++: &&, ||, !
- Арифметические и сравнения: в основном одинаковы

### Составные типы

- Python: списки [ ], кортежи ( ), словари { }

- C++: массивы тип [ ], структуры struct, std::vector, std::map

### Конецы инструкций

- Python: перевод строки

- C++: точка с запятой ;

### Комментарии

- Python: #

- C++: // и /* */
