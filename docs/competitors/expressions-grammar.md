# Сравнение синтаксиса C++ и Python

## 1. Числовые типы данных

- C++ — язык со строгой статической типизацией. Все переменные должны иметь явное объявление типа. Числовые типы
  включают:
    - int (целочисленные)
    - float (числа с плавающей точкой одинарной точности)
    - double (двойной точности)
    - long, short и их варианты
    - unsigned версии для беззнаковых чисел

- Python — язык с динамической типизацией. Числа не требуют объявления типа, они автоматически определяются
  интерпретатором:
    - int (целые, произвольной длины)
    - float (числа двойной точности)
    - complex (комплексные числа)

Итог: В Python не нужно явно указывать тип, а в C++ это обязательно. В Python целые могут быть существенно большими без
переполнения.

## 2. Арифметические операторы

- C++:
    - +, -, *, /, % (остаток от деления).
    - Для целых чисел / — целочисленное деление.
    - Инкремент/декремент: ++, --.
    - Составные операторы: +=, -=, *=, /=, %=.

- Python:
    - +, -, *, / (всегда возвращает float), // (целочисленное деление), % (остаток), ** (степень).
    - Нет операторов ++ и --.
    - Составные операторы: +=, -=, *=, /=, //=, %=, **=.

Ключевое отличие: В Python есть оператор ** для возведения в степень и // для целочисленного деления, а / всегда
возвращает float.

## 3. Сравнение приоритетов операций

- C++:
    - Высший приоритет: :: (область видимости), вызов функции, инкремент/декремент.
    - Далее: унарные операторы (+, -, !), затем *, /, %, затем +, -.
    - Полная таблица приоритетов сложна (более 20 уровней).

- Python:
    - Высший приоритет: () (скобки), ** (степень).
    - Далее: унарные +, -, ~, затем *, /, //, %, затем +, -.
    - Более простая иерархия (15 уровней).

Ключевое отличие: В Python ** имеет высший приоритет среди арифметических операторов, в C++ аналог (pow) является
функцией.

## 4. Список лево- и правоассоциативных операторов

- C++:
    - Левоассоциативные: +, -, *, /, %, <<, >>, &, |, ^.
    - Правоассоциативные: унарные операторы (++, --, !, ~), присваивание (=, += и т.д.), тернарный оператор (? :).

- Python:
    - Левоассоциативные: +, -, *, /, //, %, <<, >>, &, |, ^.
    - Правоассоциативные: **, унарные +, -, ~, присваивание (=, += и т.д.), тернарный оператор (if-else).

Ключевое отличие: В Python оператор ** правоассоциативен, в C++ аналог отсутствует.

## 5. Сравнение встроенных функций для работы с числами

- C++:
    - Библиотека <cmath>: sqrt(), pow(), abs() (для целых — <cstdlib>), sin(), cos(), ceil(), floor().
    - Перегруженные версии для float, double, long double.

- Python:
    - Встроенные функции: abs(), round(), min(), max(), sum().
    - Модуль math: sqrt(), pow(), sin(), cos(), ceil(), floor(), gcd().
    - Для комплексных чисел: модуль cmath.

Ключевое отличие: В Python многие функции встроены или доступны через модули, в C++ требуется подключение заголовочных
файлов.

## 6. Прочие особенности синтаксиса выражений

- C++ требует точек с запятой ; после выражений, Python — нет, в Python конец строки ограничивает выражение.
- В Python используется отступ для обозначения блоков кода вместо фигурных скобок {} в C++.
- Отсутствие операторов инкремента и декремента в Python меняет стиль записи циклов.
- В Python можно использовать цепочное сравнение, например, 1 < x < 10, в C++ это нужно писать через логические
  операторы.

## Ключевое отличие:

- Синтаксис тернарного оператора и цепочек сравнений в Python более читаем.
- В Python нет перегрузки операторов через функции, но есть магические методы (например, __add__).
