# Область Видимости 

1. У нас лексическая область видимости
2. Задать область видимости переменной можно задать блоком, отделенным фигурными скобками {}
3. Функция не может захватывать переменные внешней области видимости ???
4. Переменная не доступна вне своей области видимости

# Уникальность имен 

1. Имя уникально в одном блоке кода
2. Переменные и функции используют общее пространство имен
3. Переменная с локальной областью видимости перекрывает переменную с внешней
4. Имя встроенной функции можно скрыть своей переменной
5. Имя встроенного типа данных нельзя скрыть своей переменной

# Параметры функции

1. Параметры функции передаются по значению
2. Параметр функции можно скрыть локальной переменной
3. Параметру можно присвоить значение внутри функции
4. Не допускается несовпадение числа формальных и фактических параметров
5. Выражения, указанные в качестве параметров вычисляются в порядке их записи.
6. Функция может заканчиваться без оператора return, но только в том случае, если тип функции void

# Рекурсия

1. Рекурсия поддерживается в нашем языке
2. Взаимная рекурсия тоже поддерживается

# Ветвления

1. Истина (true):
    - Числа, отличные от 0 → if (10) {write(1)} → выводит 1
    - Непустые строки → if ("hello") {write(1)} → выводит 1
    - Логическое значение true
   Ложь (false):
    - Число 0 → if (0) {write(2)} else {write(1)} → выводит 1
    - Пустая строка "" → if ("") {write(2)} else {write(1)} → выводит 1
    - Логическое значение false
2. В случае, когда условие истинно, у нас выполняется ближайший после условия блок. Если условие ложно, то выполняется блок после else. Если else нет, то ничего не выполняется.
3. Выражение в условии может возвращать любой встроенный тип данных

# Циклы

1. Цикл while работает до тех пор, пока условие истинно
2. В нашем языке есть цикл for, состоящий из 3 частей:
    - Инициализация (for_initialization) - выполняется один раз перед началом цикла
    - Условие (for_condition) - проверяется перед каждой итерацией, если истинно → выполняется тело цикла
    - Инкремент (for_increment) - выполняется после каждой итерации
3. Инструкции break и continue могут использоваться только в теле цикла(for, while, do-while)
4. Выражение в условии цикла возвращает false

# Остальные правила семантики

1. Нельзя обращаться к неинициализированной переменной
2. В нашем языке есть константы. При попытке присвоить им значения возникает ошибка.
