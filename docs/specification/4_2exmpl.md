# 4_2 Примеры

## 1. SumNumbers
````
num a, b, sum;
write("Введите первое число: ");
readln(a);
write("Введите второе число: ");
readln(b);
sum = a + b;
readln("Сумма чисел: ", sum)
````
## 2. CircleSquare
````
num r, S;
write("Введите радиус окрудности: ");
readln(r);
S = Pi*r^2;
readln("Площадь окружности: ", S)
````
## 3. MilesToKm
````
num miles;
num kms;
write("Введите количество милей: ");
readln(miles);
kms = miles / 1.61;
writeln(kms)
````
