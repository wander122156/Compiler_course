# Типы Данных

bool - возвращает значение True или False
string - строковый тип данных
num - числовой тип данных, принимающий любое число

# Литералы
Литералы для типа данных bool:
- Литералом является либо True либо False

Литералы типа данных string:
- Строковый литерал заключается в двойные скобки " "
- Допускаются все символы, кроме самого знака "
  
Литералы типа данных num:
- Литералом является любое число в десятичной системе счисления с плавающей точкой(Дробное число)

# Операторы 
Семантика операторов для типа данных string:
- Операторы сравнения: ==, !=, <, >, >=, <=

Семантика операторов для типа данных num:
- Арифметические операторы: +, -, *, /, %(дел. с ост), ^(степень)
- Сравнительные операторы: !=, ==, >, <, >=, <=  

Семантика операторов для типа данных bool:
- Сравнительные операторы: !=, ==, >, <, >=, <=

# Переменные
Переменные могут быть либо просто объявлены, либо сразу присвоены
Примеры:
 num x; или num x = 5;
 string y; или string y = "Hello World!";
 bool flag; или bool flag = True;
