# Лексическая структура языка

## 1. Примеры кода

````
write("Hello!");
````

````
num n;
read(n);
write(n);
````

## 2. Ключевые слова и символы

| Слово             | Предназначение                                   |
|-------------------|--------------------------------------------------|
| if/ else/ else if | Условие                                          |
| while do(?)       | Цикл                                             | 
| and               | Логическое И                                     |
| write             | Вывод информации                                 |
| writeln           | Вывод информации с переносом на следующую строку |
| read              | Ввод информации от пользователя                  |
| readln            | Ввод информации от пользователя и перенос на следующую строку                  |

## 3. Идендификаторы

Идендификатор может:

- Начинаться только с буквы
- Иметь в названии арабские цифры или нижнее подчеркивание "_"

Идендификатор не может:

- Иметь длину менее одного символа
- Иметь в названии ключевые символы и слова

## 4. Литералы

### 4.1 Литералы чисел

Допускается:

- Литерал целого числа, состоящие из арабских цифр 0...9
- Литерал десятичной дроби, где целая и дробная часть отделяется.

### 4.2 Литералы строк

Строковый литерал заключается в двойные скобки " "
Допускаются все символы, кроме самого знака "

### 5. Набор операторов

| Тип оператора  | Доступные                             |
|----------------|---------------------------------------|
| Арифметические | +, -, *, /, %(дел. с ост), ^(степень) |
| Сравнительные  | !=, ==, >, <, >=, <=                  |

### 6. Другие Лексемы

- {} - используется как начало и конец блока кода
- ; - используется для разделения строк кода

### 7. Комментарии

- Однострочный комментарий

````
$Hello World!
````

- Многострочный комментарий

````
$$Hello World!
This is second string$$
````
