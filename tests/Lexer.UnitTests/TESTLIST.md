# Список тестов

## Класс Lexer
- [x] Разбор if без else:
  ``` 
  if (x == 1) { 
    x = x + 1;
  } 
  ```
- [x] Разбор if c else: `if (x == 1) { x = x + 1 } else { x = x + 10 }`
- [x] Разбор if c else if:
  ``` 
  if (x == 1) { 
    x = x + 1 
  } 
  else if (x == 10) { 
    x = x + 10 
  }
  ```
- [x] Разбор while do: 
  ``` 
  while (x < 10) do 
  { 
    x = x + 1 
  } 
  ```
- [x] Разбор write: `write ("hello world")  `
- [x] Разбор writeln: `writeln ("hello world")`
- [x] Разбор read: `read (a)`
- [x] Разбор and: `if (x = 1 and y = 2) `
- [x] Разбор or + регистр: `if (x = 3 or x = 4) `
