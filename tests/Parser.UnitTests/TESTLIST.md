## Требования к синтаксическому анализатору

2. Выражения могут содержать числа, операции, вызовы функций и скобки
3. Операторы могут иметь разный приоритет: например, у "*" приоритет выше, чем у "+"
4. Операторы могут иметь одинаковый приоритет: например, "*", "/", "%" имеют равный приоритет
6. Арифметические операции являются левоассоциативными: `3 * 7 / 3` означает `(3 * 7) / 3`, а не `3 * (7 / 3)`

## Список сценариев

- [ ] Разбор write без завершающего разделителя: `write ("hello")`
- [ ] Разбор write без с завершающим разделителем: `write ("hello"); `
- [ ] Разбор if без else: ` if (True) {} `
- [ ] Разбор сложения и вычитания: `if (1 + 4 - 2 == 3) {};`
- [ ] Разбор вызова функций: 
`x = min(7, 10 - 4)`
`x = max(1, 3)`
`x = abs(-4)`
- [ ] Разбор списка выражений: `x = max(2, 7 + 1.5, 10.25)`
- [ ] Учёт левой ассоциативности при вычитании: `x = 1.128 - 8 + 7.5`
- [ ] Разбор умножения и деления: `x = 4 * 7.5 / 5, 18 * 2`
- [ ] Разбор с разными приоритетами операторов: `x = 4 + 10 * 2, 16 - 7 / 4`
- [ ] Разбор скобок: `x = (4 + (5 / 4)) * 2`
- [ ] Деление по модулю: `x = 5 % 2`
