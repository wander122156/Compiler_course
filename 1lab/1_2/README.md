# Сравнительный анализ Python и C++ для фронтенда компилятора
## Ключевое отличие
В C++ статическая типизация, а в Python динамиечская.
Для фронтенда компилятора, где работа со сложнотипизированными структурами (AST, символьные таблицы, промежуточные представления) является основой, статическая проверка типов в C++ обеспечивает фундаментальное преимущество в надежности по сравнению с динамической типизацией Python.
## 1. Структурное программирование
  | C++ | Python |
  |----------|-------|
| Блоки кода: определяются фигурными скобками {} | Блоки кода: определяются отступами |
  |Циклы: for (init; condition; increment), while, do-while | Циклы: for item in collection, while |
| Условные операторы: if-else, switch-case | Условные операторы: if-elif-else, Отсутствует switch |

## 2. Операторы
  ### C++

- Арифметические: +, -, *, /, %, инкремент/декремент ++, --
- Битовые: &, |, ^, ~, <<, >>
- Сравнения: ==, !=, <, >, <=, >=
- Логические: &&, ||, !
- Присваивания: =, +=, -=, *=, /=

### Python

- Аналогичные операторы, но добавлены:
- Возведение в степень ``
- Целочисленное деление //
- Отсутствуют операторы инкремента/декремента
- Логические операторы: and, or, not

## 3. Базовые типы данных
| C++ | Python |
  |---|--------|
| Целочисленные: int, short, long, char | Целочисленные: int (произвольной точности) |
| Вещественные: float, double | Вещественные: float |
| Логический: bool | Логический: bool|
| Указатели: * | Отсутствуют указатели|
||Строковый: str|

## 4. Функции
  ### C++

````
int func(int a, float b) 
{
    return a + b;
}
````
- Строгая типизация
- Поддержка рекурсии
- Передача параметров по значению/ссылке/указателю

### Python
````
def func(a, b):
    return a + b
````
- Динамическая типизация
- Поддержка рекурсии
- Передача по ссылке на объект

## 5. Структуры данных
  ### C++
````
struct Point 
{
    int x;
    int y;
};
````
### Python
````
class Point:
    def __init__(self, x, y):
    self.x = x
    self.y = y
````
## 6. Работа со строками
  ### C++

- Массивы char[]
- Класс std::string
- Нулевой терминатор
- Фиксированная кодировка

### Python

- str — неизменяемая последовательность Unicode
- UTF-8 по умолчанию
- Богатый набор встроенных методов

## 7. Массивы и коллекции
 ###  C++

- Статические: int arr[10]
- Динамические: std::vector<int>
- Ручное управление памятью

### Python

- Динамические: list
- Неизменяемые: tuple
- Автоматическое управление памятью

## 8. Управление памятью
| C++ | Python |
  |----------|-------|
| Ручное управление: new/delete, malloc/free| Автоматическая сборка мусора|
| Ответственность за утечки памяти лежит на разработчике | Система подсчета ссылок|

## 9. Обработка ошибок
  ### C++

- Исключения: try/catch
- Коды возврата
- assert для отладки

### Python

- Исключения: try/except
- Принцип EAFP (проще попросить прощения, чем разрешения)

## Вывод
Python предпочтительнее для быстрого прототипирования благодаря лаконичному синтаксису и динамической типизации. C++ обеспечивает лучший контроль над памятью и производительностью, что критично для оптимизирующих компиляторов. Выбор зависит от требований к производительности и сложности компилируемого языка.
